# Что делать (по шагам)

1. Распакуйте архив. Внутри папка `post_explorer` — это ваш проект с уже внесёнными изменениями.
   Замените ею свою папку проекта (или скопируйте файлы поверх с заменой).
2. Откройте терминал В ПАПКЕ проекта (там, где лежит pubspec.yaml).
3. Если в проекте НЕТ папок `android` и `ios`, выполните:
   `flutter create --platforms=android,ios .`
   (если после этого появился файл test/widget_test.dart от шаблона — это НАШ файл, ничего не меняйте;
   если он оказался шаблонным со словом MyApp/counter — замените его файлом из архива).
4. `flutter pub get`
5. `dart run build_runner build --delete-conflicting-outputs`   (создаёт *.g.dart, без них проект не соберётся)
6. `dart run flutter_launcher_icons`   (генерирует иконку)
7. `flutter test`   — все тесты должны быть зелёными. Сделайте скриншот.
8. `flutter run` — запустите на эмуляторе, найдите иконку «post_explorer» на главном экране, сделайте скриншот.
9. Скриншоты вставьте в отчёт; текст отчёта — в файле ОТЧЁТ_SRS9.md.
